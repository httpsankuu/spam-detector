# 08-01-PLAN.md - Configuration Wiring

## Objective
Wire all configuration constants from `config/config.py` through their respective consumers and completely remove fragile `try/except ImportError` configuration fallback blocks. (Requirements: CFG-01, CFG-02, CFG-03, CFG-04)

## Scope
- Update `TextPreprocessor` to use `config.config` NLP parameters as defaults.
- Update `split_data.py` to use `config.config` values for data paths and ratio configurations.
- Update `logistic_regression.py`, `naive_bayes.py`, `svm_classifier.py`, and `tree_classifier.py` to consume hyperparameters (e.g. `LR_C`, `LR_MAX_ITER`, `SVM_C`, `NB_ALPHA`, `RF_N_ESTIMATORS`, etc.) from `config/config.py`.
- Remove `try/except ImportError` blocks in `trainer.py`, `metrics.py`, `plots.py`, `explainability.py`, and `split_data.py` and replace them with standard direct imports from `config.config`.
