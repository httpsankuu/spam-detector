# 08-02-PLAN.md - Feature & Benchmark Fixes

## Objective
Apply robust small-dataset guards to `TFIDFExtractor.fit_transform`, strip raw arrays from the JSON benchmark report, and fix model metadata path representation for cross-platform portability. (Requirements: FEAT-01, QUAL-03, QUAL-04)

## Scope
- Modify `src/features/tfidf_features.py` to ensure `fit_transform()` applies the same small-dataset guards for `min_df` and `max_df` as the `fit()` method.
- Update `src/evaluation/metrics.py` to exclude `y_pred` and `y_prob` from the serialized JSON benchmark report to keep it lightweight.
- Update `src/models/trainer.py` to serialize paths in `models_saved` dictionary using forward-slash POSIX paths.

## Instructions

<task>
<read_first>
- `src/features/tfidf_features.py`
- `src/evaluation/metrics.py`
- `src/models/trainer.py`
</read_first>

<action>
1. In `src/features/tfidf_features.py`: update `fit_transform` to execute `self.fit(X, y).transform(X)` instead of direct pass-through to `self.vectorizer_.fit_transform(X)` so that dataset size guards evaluate before transformation, or apply identical logic before calling `self.vectorizer_.fit_transform(X)`. Take care to convert `X` to a list if it's consumed twice.
2. In `src/evaluation/metrics.py`: delete `"y_pred": preds.tolist()` and `"y_prob": probs.tolist() if probs is not None else None` from the dictionary returned by `evaluate_model()`.
3. In `src/models/trainer.py`: wrap `model_filepath` in `Path(model_filepath).as_posix()` when adding it to the `models_saved` dictionary so that backslashes are never serialized to JSON on Windows.
</action>

</acceptance_criteria>
