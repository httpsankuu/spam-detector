# Phase 9: App Robustness & UX Fixes - Plan

## Goal
Fix Streamlit "Clear Text" button using `st.session_state`; add graceful startup error handling when models are missing; route explainability to the user-selected model; pin all package versions in `requirements.txt`.

## Requirements
- UI-01 (FIX-07): The "Clear Text" button correctly resets the text area using `st.session_state` and a `key=` parameter.
- UI-02 (FIX-08): When `models/` directory is absent, app displays a friendly informational message "Run `python scripts/bootstrap.py` first" instead of crashing.
- UI-03 (FIX-09): Feature Attribution expander routes explainability to the user-selected linear model. Gracefully explain non-linear models lack this.
- UI-04 (FIX-10): The sidebar icon is served from a local emoji or inline SVG rather than a remote URL.
- QUAL-01: `requirements.txt` pins all package versions matching the current working install.

## Dependencies
- Phase 8 must be fully completed.
- Python environment must be correctly configured with existing dependencies.
- `app/streamlit_app.py` and `src/evaluation/explainability.py` must be present.

## Implementation Steps

### 1. Fix "Clear Text" Button (UI-01 / FIX-07)
- **File:** `app/streamlit_app.py`
- **Action:** Initialize `st.session_state.user_input` to the default sample text if it isn't set. 
- **Action:** Bind `st.text_area` to this session state using `key="user_input"`.
- **Action:** Update the "Clear Text" button logic to `st.session_state.user_input = ""` and execute `st.rerun()`. Additionally, ensure that selecting a new preset from the dropdown correctly updates `st.session_state.user_input`.

### 2. Graceful Startup Error Handling (UI-02 / FIX-08)
- **File:** `app/streamlit_app.py`
- **Action:** Update `load_all_models()` to check if the `models/` directory exists (`os.path.exists`). If it does not exist, return an empty dictionary instead of throwing a `FileNotFoundError`.
- **Action:** In `main()`, check if the loaded `models` dictionary is empty. If it is, render a `st.info("Run \`python scripts/bootstrap.py\` first to train models and generate data.")` message and invoke `st.stop()`.

### 3. Route Explainability to User-Selected Model (UI-03 / FIX-09)
- **File:** `src/evaluation/explainability.py`
- **Action:** Update `SpamExplainer.__init__` to dynamically retrieve the classifier from the pipeline (instead of hardcoding `"lr"`).
- **Action:** Check if the classifier is a linear model (e.g., Logistic Regression, Linear SVM via `CalibratedClassifierCV`, or Naive Bayes). 
  - If linear, extract `self.coefficients` properly (using `coef_` or `feature_log_prob_`) and set an `self.is_linear = True` flag. 
  - If non-linear (e.g., Random Forest, XGBoost), set `self.is_linear = False` and default `self.coefficients` to empty.
- **Action:** Update `explain_text()` to return the `is_linear` flag inside its resulting dictionary.
- **File:** `app/streamlit_app.py`
- **Action:** Modify `get_explainer()` to accept a `model_path` argument so it dynamically initializes `SpamExplainer` with the model selected in the sidebar.
- **Action:** In the main feature attribution UI block, check the `is_linear` result flag. If `False`, display a `st.info` block explaining that word-level attribution is only available for linear models, and hide the standard attribution columns.

### 4. Make App Work Fully Offline (UI-04 / FIX-10)
- **File:** `app/streamlit_app.py`
- **Action:** Replace the remote URL icon (`st.image("https://img.icons8.com/...")`) in the sidebar with an offline local HTML emoji using `st.markdown("<h1 style='text-align: center;'>🛡️</h1>", unsafe_allow_html=True)`.

### 5. Pin Package Versions (QUAL-01)
- **File:** `requirements.txt`
- **Action:** Replace minimum version constraints (`>=`) with exact strict pinning (`==`). The exact versions should be retrieved from the active environment by running `pip freeze`.
