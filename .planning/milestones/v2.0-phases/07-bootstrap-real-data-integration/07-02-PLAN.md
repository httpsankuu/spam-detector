## Phase goal:
Add a `scripts/bootstrap.py` that downloads the real UCI SMS dataset, splits data, and trains all 5 models end-to-end so fresh clones work immediately; fix the `SMSDataLoader` fallback path; regenerate benchmark JSON and figures with honest numbers.

## Objective:
Create `scripts/bootstrap.py` --- an orchestrator script that chains the fixed `SMSDataLoader`, `split_dataset` + `save_splits`, `train_and_persist_all`, and the evaluation suite into a single end-to-end pipeline. Running `python scripts/bootstrap.py` on a fresh clone must produce complete `data/processed/`, `models/`, and `reports/` artifacts with no manual steps. Also ensure `pytest tests/test_pipeline.py` passes after real data exists.

## Requirements addressed:
- REPRO-01: `python scripts/bootstrap.py` on fresh clone -> data downloaded, splits, all 5 models trained & serialized, no manual steps.
- REPRO-03: After bootstrap, `pytest` passes all tests without additional manual setup.
