  <action>
    Create `src/evaluation/explainability.py`:
    1. Define class `SpamExplainer`:
       - Accepts a fitted pipeline (defaulting to `models/logistic_regression_pipeline.joblib`).
       - Methods:
         - `get_global_feature_importance(top_n: int = 20) -> dict`: Returns the top positive (spam) and negative (ham) features with their weights.
         - `explain_text(raw_text: str) -> dict`:
           - Calculates probability score and prediction verdict.
           - Extracts non-zero active features for this specific text.
           - Computes individual feature contribution = $x_i \cdot w_i$.
           - Separates active token contributions vs. active handcrafted contributions (`hc_url_count`, `hc_caps_ratio`, `hc_trigger_words_count`, etc.).
           - Identifies detected spam keywords directly in the raw text for UI highlighting.
           - Returns structured dict:
             ```json
             {
               "prediction": "SPAM",
               "probability": 0.94,
               "detected_triggers": ["urgent", "claim", "dollar"],
               "top_spam_signals": [{"feature": "...", "score": ...}],
               "top_ham_signals": [{"feature": "...", "score": ...}],
               "handcrafted_metrics": {"caps_ratio": 0.35, "url_count": 2, ...}
             }
             ```
    2. Add CLI execution (`python -m src.evaluation.explainability`) explaining a sample phishing email and legitimate email.
  </action>
