    2. Define class `HandcraftedFeatureExtractor(BaseEstimator, TransformerMixin)`:
       - Extracts numerical features from raw or processed text:
         1. `char_count`: total character count of the text.
         2. `word_count`: total whitespace-separated word count.
         3. `caps_ratio`: ratio of uppercase letters to total alphabetic characters (measures shouting/urgency).
         4. `exclamation_count`: count of exclamation marks (`!`).
         5. `question_count`: count of question marks (`?`).
         6. `dollar_count`: count of currency symbols or `dollar` tokens.
         7. `url_count`: count of URLs or `httpaddr` tokens.
         8. `email_count`: count of email addresses or `emailaddr` tokens.
         9. `digit_ratio`: ratio of digits to total characters.
         10. `trigger_words_count`: count of matched spam trigger keywords.
       - Returns a 2D numpy array of shape `(n_samples, n_features)`.
       - Implements `get_feature_names() -> list[str]` returning names of the handcrafted feature columns.
       - `fit(X, y=None)` and `transform(X)`.
    2. Include CLI self-test (`if __name__ == '__main__':`) testing on diverse spam/ham text examples.
  </action>
